# 🧗 BigWallQuest — Rejoindre la cordée automatique
**Outil :** BigWallQuest · **Version :** L7 v0.16 · **Générée le :** 2026-10-20 · ⏱ 30 secondes, une seule fois

![Schéma : coller le code une fois, ensuite tout est automatique](BigWallQuest_CordeeAuto_L7_v0.16_2026-10-20.svg)

## En 3 taps
| # | Tu fais | Tu vois |
|---|---|---|
| 1 | Ouvre le jeu → **🪢 Cordée** | « ⚡ Cordée automatique » |
| 2 | Appui long dans la case → **Coller** le message reçu → **📥 Coller le code et activer** | « ✔ Code reçu · Qui es-tu ? » |
| 3 | Touche **ton prénom** | barre de progression → « ✔ Active » |

**C'est tout.** Ensuite, à chaque ouverture du jeu, ta carte part et celles des amis arrivent toutes seules.

## Bon à savoir
- ❌ **Pas besoin de compte GitHub**, ni de fichier, ni de code compliqué.
- 📱 Si tu as touché le **lien** au lieu de coller le message, et que le jeu de l'écran d'accueil ne montre rien : colle plutôt le message dans le jeu (étape 2). Sur iPhone, Safari et l'app de l'écran d'accueil ne partagent pas leur mémoire.
- 🔄 Pour forcer une mise à jour : 🪢 Cordée → 🔄 Synchro → **Synchroniser maintenant**.
- ✖ Le message « clé refusée » apparaît ? Demande un nouveau message à l'hôte et recolle-le.
- 🔒 Ce qui est partagé avec la bande : ton prénom, ton look, tes séances. **Pas** ta sauvegarde, ni tes autres persos, ni tes problèmes Tension Board.
