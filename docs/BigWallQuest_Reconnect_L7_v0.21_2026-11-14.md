## Mode d'emploi (pour Mayo et les amis)
1. **Rien à faire au quotidien** : si tu es dans la cordée, ta sauvegarde complète part toute seule.
2. **Si tes données disparaissent** : ⚙ Options → 💾 Sauvegarde → 🔌 *Reconnect to my data* → tape ton prénom → Fusionner (ou Remplacer).
3. Une barre de progression en % s'affiche pendant la lecture.

## À savoir
- Lecture sans clé ni compte : le dépôt `Cordee` doit être **public** (réglage GitHub → Settings → Danger Zone → Change visibility).
- Public = cartes et sauvegardes lisibles par tous. Aucune donnée perso sensible dans le jeu, mais prévenir les amis.
- La clé d'écriture reste dans le code de cordée, jamais dans le jeu public ni dans les sauvegardes.
